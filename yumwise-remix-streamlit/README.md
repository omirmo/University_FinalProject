# YumWise Remix ב־Streamlit

Streamlit מגיש את מסכי הרימיקס המקוריים, עם גלילה במסכים ובחלונות הפרטים.
הממשק נמצא ב־`frontend/src`. קוד הבקשות ל־Gemini נמצא ב־`app.py`.

## הפעלה ב־Windows בלחיצה כפולה

1. ב־GitHub פתחו **Actions → YumWise for Windows**, בחרו הרצה שהסתיימה בהצלחה והורידו את **YumWise-Windows-x64** מ־**Artifacts**.
2. חלצו את כל קובץ ה־ZIP, ופתחו **`YumWise.exe`** מתוך התיקייה שחולצה. החבילה של Windows כוללת סביבת Python עבור מחשבי 64 ביט מסוג x64.
3. בפעם הראשונה הזינו בחלון את מפתח Gemini האישי שלכם מ־[Google AI Studio](https://aistudio.google.com/app/apikey). המפתח נשמר מוצפן בחשבון Windows שלכם. האפליקציה תיפתח בדפדפן.
4. כדי לסיים את ההרצה, סגרו את חלון YumWise. אפשר לשנות את המפתח דרך הכפתור **הגדרת Gemini**.

להפעלה ישירות מתיקיית קוד המקור, התקינו פעם אחת [Python ל־Windows](https://www.python.org/downloads/windows/) ופתחו בלחיצה כפולה את `Open-YumWise-Windows.cmd`. הקובץ מתקין את החבילות לפי הצורך, פותח את עורך הטקסט להגדרת המפתח בפעם הראשונה, ומפעיל את YumWise.

## הפעלה ב־Mac בלחיצה כפולה

לחצי פעמיים על `YumWise.app` מתוך תיקיית `yumwise-remix-streamlit`.
כשהאפליקציה מוכנה, היא נפתחת בדפדפן ברירת המחדל. ליציאה, בחרי **יציאה מ־YumWise**
בתפריט האפליקציה או ב־Dock. היציאה סוגרת גם את השרת המקומי.

אם הפתיחה דרך `YumWise.app` נכשלת, לחצי פעמיים על `Open-YumWise.command`.
הקובץ מפעיל את YumWise אוטומטית בחלון מסוף. סגירת חלון המסוף מפסיקה את ההרצה.

המפעיל משתמש בסביבת `.venv` של הפרויקט, או בסביבה המותקנת בתיקייה
`Desktop/yumwise-demo/.venv`. במק חדש שעדיין אין בו סביבת Python עם החבילות,
התקיני אותן פעם אחת מתוך תיקיית הפרויקט:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

## Gemini

אם המפתח כבר מוגדר ב־`Desktop/yumwise-demo/.streamlit/secrets.toml`, YumWise קוראת
אותו אוטומטית כשאין מפתח בהגדרות של העותק הנוכחי. כדי להגדיר מפתח לעותק הזה,
צרי בו את `.streamlit/secrets.toml` עם ההגדרה:

```toml
GEMINI_API_KEY = "YOUR_API_KEY"
# GEMINI_MODEL = "gemini-3.5-flash-lite"
```

במסך **לכתוב**, הקלידי בקשה כגון ״בא לי משהו פריך ומלוח כמו מלאווח״,
לחצי על כפתור הסיום ואשרי את הבקשה. Gemini יוצר את החלופות בזמן הבקשה,
לפי הניסוח, ההעדפות והכמות שנבחרה באזור ההורים (1–5).
תוצאות כתיבה שנוצרו באמצעותו מסומנות במסך התוצאות. אם הבקשה נכשלת,
מסך התוצאות מציג את התקלה ומאפשר להתחיל בקשה נוספת.

הציור מציג את דוגמאות ההדגמה של הרימיקס, ובמסך הדיבור ההקלטה וההשמעה
נשארות בדפדפן. קוד הדמו להורים הוא `1234`.

## עריכת הממשק

קובצי הממשק בעברית ובכיוון ימין לשמאל נמצאים ב־`frontend/src`. הגרסה הבנויה
כבר כלולה ב־`frontend/dist`. אחרי עריכה בקוד הממשק, בנו אותו מחדש מתוך
`frontend` באמצעות `npm ci` ו־`npm run build`.
